# UWTSD Pandemic: Campus Outbreak Response

Responsive browser prototype for **ACCB6017 Usability Engineering – Component 2: Full Interface & Testing**.

The single-file prototype contains eleven linked interface stages: Start, Play Mode, Create/Join, Campus, Role, Outbreak Map, Alert, Player Action, Cure Progress, Team Status and Mission Result.

It includes mobile, tablet and desktop layouts, keyboard focus, large-text and high-contrast controls, labelled buttons, room-code validation and non-flashing alerts.

Open `index.html` through GitHub or download it and open it in a modern browser. This is a usability prototype; networking, authentication, databases and full game algorithms are outside its scope.
